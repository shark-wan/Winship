Winship 是什么

单机、单虚拟机的本地控制面

Winship 管理本机的一台 Windows 虚拟机。它固定使用 Q35、OVMF/UEFI、VirtIO Balloon，并允许把 NVIDIA 显卡、USB 控制器、单个 USB 设备或整块物理移动磁盘交给 Windows。

Windows 画面直接从直通显卡的物理输出口输出。本项目不提供 RemoteApp、FreeRDP 窗口合成、Looking Glass 或远程显示。

PCI 直通风险

错误的设备或 IOMMU 分组可能让宿主机失去显示或输入设备

  • 应用 VFIO 配置前，逐项核对 PCI BDF 地址与 IOMMU 分组。
  • 不要把 Debian 正在使用的核显、NVMe 控制器或键盘鼠标所在 USB 控制器直通给 Windows。
  • VFIO 绑定在重启后生效；Winship 不会自动重启宿主机。
  • 务必保留恢复手段，包括另一台设备、SSH 或 Live USB。

认证与访问

本地服务也需要访问控制

Winship 默认监听 0.0.0.0:15277。所有页面与 API 都需要 /etc/winship/token 中的 token，登录后写入 HttpOnly、SameSite=Strict Cookie。

请在受信任的本机浏览器使用。若不需要局域网访问，建议通过防火墙限制 15277 端口，或设置 WINSHIP_LISTEN=127.0.0.1:15277。

磁盘与关机

数据安全提示

  • 物理整盘直通后，该磁盘在宿主机侧不可见，不能同时挂载。
  • 强制停止相当于断电，仅在正常关机无效时使用。
  • 删除虚拟机定义不会删除 qcow2、ISO 或物理磁盘数据。
  • Windows 内安装 VirtIO Balloon 驱动后，宿主机才能回收闲置内存。
